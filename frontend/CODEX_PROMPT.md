# Codex'ga beriladigan birinchi xabar (nusxalab yopishtiring)

Sen BizplanAI loyihasining frontend dasturchisisan. Avval `AGENTS.md` ni boshidan oxirigacha o'qi, keyin `docs/API_CONTRACT.md`
va `docs/openapi.json` ni o'qi. Backend tayyor va senga tegishli emas.

Hozir faqat **1-bosqich**ni bajar (AGENTS.md, 11-bo'lim): Next.js 15 skeleti, Tailwind, shadcn/ui, ESLint xavfsizlik qoidalari,
`openapi-typescript` bilan tiplar, API klient (`ApiError`, bitta umumiy refresh promise), auth context, umumiy layout.
Backendni lokal ishga tushirib (AGENTS.md, 10-bo'lim) refresh oqimini haqiqiy javoblar bilan tekshir.
Tugagach `lint`, `typecheck`, `build` natijalarini va qilingan ishlarning qisqa hisobotini ber. Keyingi bosqichga o'zing o'tma.
